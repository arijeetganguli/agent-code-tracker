Features

📊

Real-Time Tracking

Monitors every keystroke and paste. Heuristics detect AI-generated vs manually-typed code based on insertion size, code patterns, and context.

🎯

Per-File & Workspace Stats

See agent code percentage for each file individually and aggregated across the entire workspace.

🪙

Token Usage Tracking

Estimates token consumption per change (~4 chars/token). Track how many tokens your AI agent is using over time.

📋

Shareable Reports

Export usage reports as JSON, standalone HTML, or copy a text summary to clipboard. Share with your team or manager.

⚙️

Project-Level Config

Enable or disable tracking per workspace folder. Configure thresholds and visibility in workspace or folder settings.

📌

Status Bar Integration

Always-visible agent percentage in the status bar. Click to open the full statistics panel.

Installation

From VSIX file:

code --install-extension agent-code-tracker-0.0.1.vsix

Configuration (settings.json):

{ "agentCodeTracker.enabled": true, "agentCodeTracker.minCharsForAgent": 30, "agentCodeTracker.showStatusBar": true, "agentCodeTracker.trackTokenUsage": true }
