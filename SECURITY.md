# Security Policy

## Supported Versions

Security fixes are provided for the latest release on the main branch.

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Report vulnerabilities by email to: cooldevil.ari@gmail.com

Please include:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested remediation if known

You will receive an initial response within 3 business days.

## Disclosure Policy

- We will acknowledge receipt and triage the report.
- We will work on a fix and validate impact.
- We may request additional details during investigation.
- We will coordinate a disclosure timeline with the reporter when possible.
